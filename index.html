01 — 关于我

从电路图到内核，再到用户态

我是赵嘉程，2021 年毕业于西安邮电大学计算机科学与技术专业，2022 年加入浙江九州量子， 做量子随机源设备的软件研发：写客户端 SDK、维护设备服务程序、改设备树与固件、做性能调优。

我的工作常常横跨好几层——上到 Qt / Windows 客户端与密钥管理系统网页，下到 u-boot、kernel、 文件系统和 USB 固件。我比较擅长把一件事从「能跑」推到「跑得稳、跑得快」： 曾把设备输出极限速率提升约 15%，也把 800 亿条数据的查重从 8～10 小时压到 3.5 小时。

性格上偏踏实：做事讲条理，习惯先整理文档再动手；抗压能力不错，遇到问题愿意一层层往下查。 业余喜欢摄影、篮球和跑步。

目前在西安，主要看嵌入式软件、Linux 开发方向的机会；也欢迎技术交流。

  • Linux
  • SDK / JNI

光量子随机数发生器

2022.04 – 2022.07

对设备做整体原理性探究：拆解分析电路与固件资源，基于 Cypress 官方文档与工具研究 USB 通信、 确定传输端点，完成固件替换并保证设备运行正常；梳理相关技术文档、论文与专利，向上级做预研汇报。

  • USB
  • 固件分析

大数据量纯 k 查重工具

2023.07 – 2023.08

依据国家标准中对大数据量纯 k 查重的定义，独立设计并实现查重与定位算法，完成 800 亿条样本的处理； 解决大小端、样本提取、快速查重、比特流定位与结果筛选等问题，设计样本结构以支持 k 值变化。 整体耗时 3.5 小时（原非纯 k 算法 8～10 小时），存储占用减少 200G。

  • C / C++
  • 算法
  • 数据结构

除此之外还参与过：密钥管理系统网页开发与国密算法访问改造、客户端 SDK 接口与通信模块开发、 可信平台模块与 5G RedCap 技术预研、设备生产资源整理与固件打包烧写流程。 本科毕业设计为《基于三维卷积神经网络的遥感图像分析及系统设计》（Indian Pines 高光谱数据集分类）。
